# 🏐 Lake Huron Volleyball Club (Ospreys)

> Official web platform for the **Lake Huron Volleyball Club**, serving youth athletes and families across Petrolia, Wyoming, and Lambton County communities in Ontario, Canada.

---

## 📌 Project Overview

The **Lake Huron Volleyball Club Platform** is a custom, modern web application built to represent the club’s athletic programs, community focus, and commitment to the **Ontario Volleyball Association (OVA)** core values (*Accountable, Excellence, Collaborative, Intentional, Sustainable, Integrity & Respect*).

It provides prospective families and athletes with clear pathways to join competitive youth travel teams (U16 & U18), skill development camps, and house leagues.

---

## ✨ Key Features

- **Hero Experience:** High-impact animated introduction with brand crest framing and responsive mobile layout.
- **`Our Story & OVA Core Values:** Narrative highlighting local Lambton County roots and 6 OVA-aligned core values.
- **Programs & Player Journey:** Detailed breakdown of competitive travel teams and a visual 4-stage athlete progression roadmap.
- **Coaching Staff Roster:** Profiles featuring technical experience and OVA coaching certifications.
- **Interactive FAQ Accordion:** Categorized Q&A answering tryout, fee, and commitment questions.
- **Multi-Select Contact Engine:** Lead generation form with flexible inquiry options.
- **Full Responsiveness:** Optimized across 19 screen breakpoints (320px to 2560px).

---

## 🛠️ Technology Stack

- **Framework:** Next.js 15.1 (App Router)
- **UI Library:** React 19
- **Language:** TypeScript 5.5 (Strict Mode)
- **Styling:** Tailwind CSS 3.4 & Vanilla CSS Custom Properties
- **Icons:** Lucide React

---

## 🚀 Quick Start Guide

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 3. Build for Production
```bash
npm run build
npm run start
```
