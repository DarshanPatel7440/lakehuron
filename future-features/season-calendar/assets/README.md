# Assets Directory

This folder is reserved for future visual assets related to the Season Calendar.

## Planned Assets

| Asset | Type | Purpose | Status |
|---|---|---|---|
| `calendar-hero.jpg` | Photo | Optional hero/header image for the calendar section | Not yet created |
| `empty-state.svg` | Illustration | Shown when no events match filters | Not yet created |
| `venue-icons/` | SVG icons | Custom venue type icons (gym, beach, hall) | Not yet created |
| `category-badges/` | SVG/PNG | Custom category badge graphics | Not yet created |

## Guidelines

- All images should be optimized for web (WebP preferred, JPEG fallback)
- SVG illustrations should use the brand color palette
- Use `next/image` for all raster images
- Maximum image dimensions: 1200×800px for hero, 48×48px for icons
- Maintain consistent visual language with existing site imagery
